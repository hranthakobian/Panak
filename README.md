# Panak (Պանակ) – Android-ոճի Popup թղթապանակների համակարգ Windows-ի համար

**Panak**-ը ժամանակակից, սահուն եւ արագ աշխատող ծրագիր է Windows օպերացիոն համակարգի համար (C# / .NET 8 WPF), որը թույլ է տալիս նիշքերն ու թղթապանակները կառավարել **Android OS-ի թղթապանակների (Folder Widgets)** ոճով։

---

## 🌟 Հիմնական առանձնահատկությունները

1. **Սահուն Scale & Morph անիմացիա**
   - Պանակը բացվում է անմիջապես պատկերակի էկրանային կոորդինատներից (կամ կենտրոնից, եթե միացված է կենտրոնում բացման կարգավորումը)՝ սահուն խոշորանալով եւ վերածվելով ապակեպատ Popup պատուհանի:
   - Փակվելիս պատուհանը սահուն փոքրանում է եւ կրկին դառնում պատկերակ:

2. **Դինամիկ 2x2 Preview պատկերակ (Dynamic Icon Engine)**
   - Պանակի պատկերակը դինամիկ կերպով ցույց է տալիս դրա ներսում եղած առաջին 4 նիշքերի նախադիտումը (2x2 Grid Preview)՝ Android-ի ոճով:
   - Նիշք ավելացնելիս կամ հեռացնելիս պատկերակը Windows Explorer-ում ակնթարթորեն թարմանում է:

3. **Windows Context Menu ինտեգրում**
   - Explorer-ում նիշք(եր) նշելիս աջ կտտոցով հասանելի է **«Ստեղծել Android-ոճի պանակ»** հրամանը:
   - Windows-ի ցանկացած սովորական պանակի վրա աջ կտտոցով հասանելի է **«Բացել Panak-ով»** հրամանը:

4. **Արագ բացում (Right Double-Click & Quick Look Hotkey)**
   - **Right Double-Click**՝ Windows-ի ցանկացած թղթապանակ բացվում է Panak Popup տեսքով աջ մկնիկի կրկնակի կտտոցով:
   - **Quick Look (Space)**՝ Explorer-ում ցանկացած պանակի վրա `Space` սեղմելիս վայրկենապես բացվում է դրա պարունակությունը: `Space` կամ `Esc` կրկին սեղմելիս այն փակվում է:

5. **Focus Mode (Ֆոկուսի ռեժիմ)**
   - Պանակը բացվելիս էկրանի ետեւի ֆոնը մթագնում է՝ ուշադրությունը կենտրոնացնելով պանակի վրա: Ֆոնի վրա կտտացնելիս պանակը սահուն փակվում է:

6. **Drag & Drop**
   - Նիշքերը կարելի է քաշել-գցել ինչպես բացված Popup-ի մեջ (ավելացնելու համար), այնպես էլ Popup-ից դուրս՝ Desktop կամ այլ պանակներ:

7. **Պանակի խմբագրում (✏️ Inline Editor)**
   - Մատիտի կոճակով կարելի է փոխել պանակի անունը, գունային թեման (Color Swatch) եւ պատկերակի ձեւը (Squircle, Circle, Rounded Square, Teardrop):

8. **System Tray & Կայանքներ**
   - Ծրագիրն աշխատում է tray-ում (սկուտեղում):
   - Կայանքներից կարելի է ընտրել ցանցի սյուների քանակը (3-8, լռելյայն՝ 5), լեզուն (ՄԱԿ-ի բոլոր 6 լեզուները եւ Հայերեն), միացնել էկրանի կենտրոնում բացումը, կողպել պանակները (Locking) եւ կառավարել Focus Mode-ի մթագնման աստիճանը:

## 🚀 Տեղադրում եւ Ապատեղադրում (Installer & Uninstaller)

### Տեղադրում (Install)
Կարող եք տեղադրել հետեւյալ եղանակներից որեւէ մեկով.
- Գործարկեք **`Install.bat`** նիշքը, կամ
- Հրամանի տողից (CMD/PowerShell)՝ `Panak.exe --install`, կամ
- Բացեք Panak-ի Կայանքները (Settings) եւ սեղմեք **«Install»** (Տեղադրել) կոճակը:

Տեղադրիչը ինքնաշխատ կերպով.
- Ծրագիրը պատճենում է `%LocalAppData%\Programs\Panak\` թղթապանակում (առանց Administrator իրավունքների անհրաժեշտության):
- Ստեղծում է Desktop-ի եւ Start Menu-ի դյուրանցումները (Shortcuts):
- Գրանցում է Explorer-ի աջ կտտոցի (Context Menu) ընտրանքները:
- Գրանցում է Panak-ը Windows-ի «Installed apps / Ծրագրերի ավելացում եւ հեռացում» բաժնում:

### Ապատեղադրում (Uninstall)
- Գործարկեք **`Uninstall.bat`** նիշքը, կամ
- Հրամանի տողից՝ `Panak.exe --uninstall`, կամ
- Windows-ի Settings > Apps > Installed apps բաժնից ընտրեք **Panak** եւ սեղմեք **Uninstall**:

Ապատեղադրիչը մաքրում է գրանցամատյանի (Registry) բոլոր գրառումները, context menu-ները, դյուրանցումները եւ հեռացնում է ծրագրի նիշքերը:

## 🛠️ Կառուցում (Build) եւ Թեստավորում (Testing)

```bash
# Ծրագրի կառուցում
dotnet build

# Ավտոմատ թեստերի գործարկում
dotnet test

# Release հրատարակում
dotnet publish -c Release -r win-x64 --self-contained false -o publish Panak.csproj
```
